# 화면 언어(ko/en, v0.15.0~)

화면 문구는 한국어와 영어 두 언어다. 언어 처리는 GameKit `@bloom-gamekit/i18n`(`createLocale`)을 쓰고, 문구 표는 이 저장소의 `src/i18n/`이 소유한다.

## 언어를 정하는 순서

페이지를 읽을 때 한 번 정하고, 경기 중에는 바뀌지 않는다(`src/i18n/locale.js`).

1. 주소의 `?lang=ko|en`
2. 설정 창에서 고른 언어(저장 키 `bloom-takraw-locale`)
3. 브라우저 언어 목록에서 처음 맞는 것
4. 없으면 `en`

설정 창의 언어 줄에서 고르면 저장한 뒤 `?lang=`으로 새로고침한다. 경기 중에는 막는다. 확인용 주소(`?debug`)와 소개영상 화면(`?showcaseDemo=1`)은 저장 격리와 같은 조건이라 저장한 선택을 읽지도 쓰지도 않는다. 소개영상 호스트(`installShowcase({ locale })`)는 iframe 주소에 같은 `?lang=`을 붙인다.

## 누가 문장을 만드나

| 층 | 가지는 것 | 예 |
| --- | --- | --- |
| 시뮬레이션·모델 | 코드와 값(`message(id, values)`) 또는 정의 데이터의 TextPair `{ ko, en }` | `lastMessage = { id: 'point', values: { team: 1, reason: 'serveLine' } }`, 레슨 제목, 학교 이름 |
| 클럽 모델 | 상태 코드 `club.message = { id, values }`, 오류의 `code`·`values` | `{ id: 'creditsShort', values: { short: 20 } }` |
| 화면 | 코드 → 문장 | `matchText(ref, localTeam)`, `clubText(ref)`, `LOCALE.text(pair)` |

시뮬레이션은 언어를 모른다. 득점 사유·결과 판정은 코드(`serveLine` 등)로 비교한다. `values.team`은 팀 번호(0|1)이고, 화면이 내 팀 기준의 `own`으로 바꿔 읽는다.

## 문구 표

| 파일 | 내용 |
| --- | --- |
| `src/i18n/messages/page.js` | `index.html`의 고정 문구(`data-i18n`, `data-i18n-<속성>`)와 부팅 문구 |
| `src/i18n/messages/match.js` | 경기·연습 안내(`MATCH`), 득점 사유(`REASON`), 연습 결과 |
| `src/i18n/messages/ui.js` | 화면(`UI`)과 클럽 상태·오류(`CLUB`) |
| `src/i18n/messages/runtime.js` | 연결·보상·소리 저장·부팅 오류(`RUNTIME`) |

`LOCALE.messages(table)`은 키마다 ko·en이 모두 있어야 하고 모르는 키를 부르면 예외를 낸다. 값이 있는 문구는 함수(`({ count }) => …`)로 쓴다. 조작 이름은 PC 기준(좌클·left click)으로 쓰고, 터치 화면은 `touchControlText`가 발차기 버튼으로 바꾼다.

## 이름

- 게임 이름: `TAKRAW_GAME_NAME`·`TAKRAW_PRODUCT_NAME`(`src/config/game.js`). 영어 제품 이름은 `Bloom Takraw`이고 페이지 기본 언어(en)라 `<title>`, PWA 설치 이름, 공유 문구가 이 이름이다(`scripts/pwa.mjs`, `scripts/check.cjs`가 맞춘다). README·AGENTS·package.json은 한국어 이름을 쓴다.
- 선수 이름: `src/club/names.js`의 한국어·로마자 짝. 생성 카드는 한국어 이름만 저장하고 화면이 짝을 찾는다. 특징 문구(tag)는 저장하지 않고 능력치로 만든다(`takrawCardTag`).
- 학교 이름은 뜻을 옮긴다(새싹고 → Sprout High).
- 사용자가 지은 팀 이름은 번역하지 않는다. 새 클럽의 기본 이름은 처음 만든 언어로 저장된다.

## 시험

고정 시나리오(`tests/user-flow.spec.js`, `tests/mobile-flow.spec.js`)는 `locale: 'ko-KR'`로 한국어 문구를 본다. 영어 화면은 영구 시험에 두지 않고, 바꿀 때 1회용 캡처로 확인한다.
