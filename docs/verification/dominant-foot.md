# 주발(오른발) 기준 (v0.12.46)

## 규칙
- 차는 발의 기본은 오른발이다(`physics.dominantFoot.side`, 한 곳에서 바꾸면 좌우 대칭으로 적용).
- 지상: 공이 몸 중심에서 왼쪽으로 `groundOffset`(0.25 m)을 넘어갈 때만 왼발.
- 공중: 왼발 발바닥이 공에 `airMargin`(0.05 m) 넘게 더 가까울 때만 왼발. 같은 거리면 오른발.
- 선수 초기 차는 발도 오른발.

## 이미 오른발 기준이던 것(바꾸지 않음)
- 공 목표 옆 이동 0.10 m(`ai.toss.attack.lateral`): 세트 목표(`kickIntent`), 접근 자리(`approachPosition`), 받기 자리(`physics.planReceive`), 서브 공(`holdServeBall`·AI 서브), 속공 접촉점(`feedQuick`), 연습 토스(`training.feed.lateral`). 팀 0 기준 공이 몸 중심에서 오른쪽(−z) 0.10 m라 오른발(−z 0.12 m)과 맞는다. 팀 1은 방향 부호(`toward`·`n`)로 대칭.
- 동작 데이터(`motion/data.js`): 오른발 기준으로 쓰고 왼발은 `mirror = −1`로 뒤집는다.

## 측정(AI 대 AI 3경기 70초, 지상·공중 발 접촉)
- 변경 전: 공중 공격수 R 35 · L 1, 지상 받기 R 43 · L 1, 지상 세터 R 36 · L 1.
- 변경 후: 공중 공격수 R 34, 지상 받기 R 45 · L 1, 지상 세터 R 36 · L 1, 지상 공격수 R 3 · L 1.
- 사람 속공·고공 연습 봇(`scene-quick.mjs`): 각 12번 모두 오른발.
- 영향: AI 경기에서는 거의 변화가 없다(이미 오른발 97% 이상). 달라지는 경우는 공이 몸 중심 가까이(좌우 0.25 m 안, 공중은 발 거리 차 0.05 m 안)일 때뿐이다.

## 영향 범위
| 영역 | 영향 | 확인 |
|---|---|---|
| 지상 받기·세트·서브 발차기 | 중심 가까운 공은 오른발로 | 테스트 통과 |
| 공중 공격(스파이크) | 중심 가까운 공은 오른발로 | 속공 연습 봇 12/12 |
| 블로킹 | 공이 몸 왼쪽 0.1 m 안팎이면 왼발이 필요했다. 오른발로 바꾸면 이 구간에서 되받기 실패. `airMargin`을 0.1 이상으로 키우면 `block.spec`이 깨진다 | `block.spec` 통과(0.05) |
| 슬라이드 받기 | 같은 지상 선택 규칙 | 받기 테스트 통과 |
| 공중 서브(긴 토스) | 공이 가운데면 오른발 | 봇 |
| 학습·AI 두뇌 | 발 선택을 쓰지 않음 | `ai-brain`·`match-learning` 통과 |
