# 일반 지상 토스의 팔 자세 수정 (v0.12.23)

학교 표시 1단계와 분리한 선행 버그 수정이다. 기준 main은 `fbf04e04ff789b21ab3f1e755fc29b7d0238ac14`이다.

기존 `tests/user-flow.spec.js:104`의 일반 서브 10회에서 리시버→세터→공격수의 세 번째 스파이크 네트 통과율 80% 검사가 변경 없는 main에서도 60%로 실패했다. 무작위 경기 seed를 기존 E2E가 기록하지 않아 당시 seed는 알 수 없다. 진단용 매 물리 step 관찰도 60%였고, 실패는 실제 핸드 반칙·네트 아래 통과·아웃이었다. 관찰기 변경은 원복했다.

## 원인과 최소 수정

`physics.js`의 지상 `cushion` 토스는 발 접촉을 계획하면서 팔은 기본 자세에 남겼다. 팔을 접는 기존 동작은 런지·슬라이딩과 공중 공격에만 적용됐다. 기본 손 높이는 약 0.785m로 지상 토스 접촉 높이 0.75m와 겹친다. 공이 상승할 때 손·정강이 선행 접촉과 불안정한 토스가 이어질 수 있었다.

일반 지상 토스에도 기존 어깨·팔꿈치·몸통 준비 자세를 적용한다. 새 힘·보정 임펄스·성공 주입·충돌 제외·시드 선택을 추가하지 않았다. 모든 몸체와 충돌체, 한계가 있는 관절 모터, 실제 발 접촉으로 결과가 결정된다. 시뮬레이션 tick/step 횟수·AI 해시·입력·snapshot 필드 계약은 유지한다.

## 제한된 재현

실제 Rapier 0.21.0 Node 실행, 기본 클럽 3명, 우리 공격수의 6바이트 0입력, 첫 우리 서브 5랠리. 변경 전 고정 seed1은 3/5, seed2는 5/5였다. seed1 실패는 rally6의 정강이 리시브(tick3183) 뒤 낮은 세트·바닥 접촉, rally8의 정강이 세트 뒤 조기 반환이다. 변경 후 같은 seed1은 5/5이며 모두 foot 접촉으로 리시브→세트→공중 공격→네트 통과했다. 다른 seed의 결과와 필수 검사 결과는 PR에 남긴다. 이 소수 표본은 모든 seed의 성공률 보장이 아니다.

로컬 실행 자료는 Git 제외 `artifacts/seed1-trace.json`, `artifacts/school-01/seed-reproduction.json`이다. 임시 진단 실행 코드는 영구 테스트에 추가하지 않는다. 기존 80% 기준과 고정 사용자 흐름은 유지한다.
