# 타격감 이펙트 검증 (v0.12.19)

기준 문서: bloom-reference `rules/impact-feel.html`(타격감 종합 가이드) §3 접촉·§6 밀도·접근성·§7 멀티·롤백.

## 추가한 연출
| 사건 | 연출 | 소유 |
|---|---|---|
| 모든 발 접촉 | 접점 별 섬광, 링·입자(팀 색), 공이 맞은 방향으로 눌렸다 복원(squash) | `presentation/impact.js` |
| 굿·퍼펙트 | 속도선, 화면 확대, 퍼펙트는 화면 흔들림 | 같음 |
| 스파이크(`spike` 플래그) | 큰 충격파 2겹, 속도선 12개, 화면 흔들림 6px, 화면 확대 6%, 공 눌림 34%, "SPIKE!" 팝업, 전용 소리 `kickSpike` | impact.js, `ui.js`, `config/runtime.js` |
| 선수 착지(속도 2.2 m/s 이상) | 바닥 먼지 | `presentation/field-effects.js` |
| 득점 | 득점 팀 코트 위 색종이 44개 | 같음 |

값은 모두 `config.visual.impact` / `visual.field` / `visual.shakeCap`에 있다.

## 가이드 적용 결과
- 접점·방향 일치: 섬광·눌림 방향·속도선 축은 접촉 이벤트의 위치와 발 속도다.
- 흔들림: 여러 접촉이 겹쳐도 합산하지 않고 가장 센 하나만, 상한 6px. 단위가 px라 화면 크기와 무관(월드 변환은 초점 거리 기준).
- squash: 외형만 변한다(위치·회전·콜라이더 불변). 최대 55%까지, 부피 보존, 복원 후 자동 갱신으로 돌아온다.
- 마무리 구분: 일반 접촉은 작은 섬광, 스파이크·득점만 큰 연출. 색종이는 확정된 득점에만 터진다.
- 효과 축소(OS 동작 줄이기): 흔들림·화면 확대·눌림·속도선·색종이·착지 먼지 모두 끈다. 섬광·링과 "SPIKE!" 문구는 남겨 정보는 유지한다.
- 멀티·롤백: 접촉·착지는 `speculative`(되돌릴 수 있는 자원), 득점은 `confirmed`. 입자 방향은 tick·sequence 시드 난수라 두 피어가 같다. 시뮬레이션 상태를 읽거나 쓰지 않는다.
- hitstop(규칙 정지)은 넣지 않았다. 가이드가 조건부·롤백 계약 필요로 분류했고, 현재 공 물리가 연속이라 표현만 멈추면 접점이 어긋난다.

## 검증 (헤드리스 Chromium + 로컬 three, 렌더 하네스)
| 항목 | 결과 |
|---|---|
| squash 부피(행렬식) | 모든 나이에서 1, 위치 불변 |
| squash 복원 | 600ms에 0, 정리 후 `matrixAutoUpdate` 복귀 |
| 흔들림 합성 | 스파이크 3개 동시: 6px(합산 아님), 상한 이하 |
| 효과 축소 | 흔들림 0, 화면 확대 없음, 눌림 없음 |
| 정리 | 효과 해제 후 활성 0, 시야각 기준값 복귀 |
| 풀 재사용 | 접촉 노드 3, 지면 노드 2(80회·80회 시작/해제 후) |
| 결정론 | 같은 tick·sequence에서 입자 방향 동일 |

## 미검증
- 실제 게임 화면(index.html) E2E: 이 환경은 CDN에 접근할 수 없어 실행하지 못했다. "SPIKE!" 팝업(DOM)과 소리, 390px 폭 배치는 눈으로 확인하지 못했다.
- 온라인 롤백 중 취소·재확정 경로, 저사양 프레임 비용.
- 효과를 하나씩 끈 비교(가이드 §8)는 사용자 플레이 판단이 필요하다.

## 스파이크 속성 입자 (v0.12.55)

- 검증: 헤드리스 Chromium(SwiftShader)에서 10개 속성을 0.12·0.30·0.55·0.85초로 렌더링해 모양·색·수명을 눈으로 확인했다.
- 노드 검증(THREE 직접 실행): 속성 id와 학교·설정표가 1:1, 모든 속성의 입자 합 ≤ 40, 입자 수명 ≤ 1.2초, 같은 tick·sequence·경과 시간이면 같은 위치·크기, 프레임 간격과 무관, 모션 줄이기 입자 40%, 모든 시각에서 위치·크기가 유한하고 접촉점에서 6 m 이내, 스파이크가 아닌 접촉은 입자·궤적 색 없음, 팀 번호별 속성 적용, dispose.
- 목업 대비 생략: 바닥에 붙는 효과(물결·땅 갈라짐·새싹·서리 결정), 달빛 기둥, 햇빛 코로나는 접촉점이 공중이라 넣지 않았다.

## 속성 입자 가독성 (v0.12.57)

- 근거: 효과는 채도가 높을수록 시선이 모이고, 팔레트는 극단(0·100)을 피해 중간 밝기로 잡으며, 배경과는 명도 차이로 분리한다([LoL VFX 가이드](https://www.vfxapprentice.com/blog/10-league-of-legends-vfx-design-tips), [Game Developer](https://www.gamedeveloper.com/design/how-to-reduce-visual-confusion-in-your-game)).
- 조치: 입자·링·궤적 색의 채도를 올리고 밝기를 중간 범위로 내렸다(흰색은 포인트만). 입자 뒤에 속성별 어두운 테두리를 깔았다. 바람·땅·달빛·어둠은 색 정체성(청록·갈색·라벤더·보라)이 바뀌어 수동으로 되돌렸다.
- 확인: 실제 게임 화면에서 10개 속성을 0.13초·0.40초에 캡처해 눈으로 확인했다.
