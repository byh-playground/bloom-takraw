# 입력 자유도 2단계: 사람이 자리를 비울 때 동료가 빈자리를 채운다 (v0.12.35)

## 동작
- 공이 상대 쪽에 있고 사람이 있는 팀에서만 동작한다. 사람이 없는 팀(AI 대 AI, 학교 사다리)과 훈련 모드는 그대로다.
- `AiFormation`(`src/simulation/ai-formation.js`)이 사람 위치를 기준으로 우리 코트 격자(0.5 m)의 도달 시간을 계산하고, 동료 2명의 기준 자리를 도달 시간 손실이 가장 작은 쌍으로 옮긴다.
- 사람이 제 자리에 있으면 개선 폭이 `minGain` 미만이므로 기존 대형을 그대로 쓴다.
- 현재 상태만으로 계산하는 순수 함수이므로 롤백·동기화 상태(`save()`)에는 추가 항목이 없다.

## 측정 (`node scripts/scene-cover.mjs`, 사람 위치 6곳 평균)
| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 0.9초 안에 못 닿는 면적 비율 | 8.1% | 3.5% |
| 평균 도달 시간 | 0.506초 | 0.475초 |

- 계산 비용: 15 Hz 호출당 약 1.1 ms.
- 테스트: `tests/formation.spec.js` 3개(제자리면 유지, 빈 쪽으로 이동·결정적, 역할별 범위 준수).
