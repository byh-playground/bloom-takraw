# 동료 AI 학습 기능 (v0.12.13)

2026-10-27. 학습 코어([learning-core.md](learning-core.md))를 유저 기능으로 연결했다.

## 동작

1. 홈 → 내 팀 관리 → "동료 AI 학습" 버튼으로 학습 화면을 연다.
2. 훈련 포인트 1 P로 학습을 시작한다. 같은 스파이크 16개로 학습 전 성공률을 재고, 스파이크 100번 받기(REINFORCE, 장면마다 화면에 양보)를 돌리고, 4비트로 양자화한 가중치로 학습 후 성공률을 잰다.
3. 끝까지 마친 경우에만 포인트 1을 차감하고 정책(base64 약 190자)과 누적 횟수를 클럽 레코드에 저장한다. 중간에 멈추거나 오류가 나면 포인트도 저장도 바뀌지 않는다.
4. 다음 로컬 AI 대전부터 우리 팀 동료는 상대 스파이크마다 정책이 낸 조정 값을 쓴다. 학습 이력이 있으면 저장된 가중치에서 이어서 학습한다.

## 규칙의 위치(SSOT)

- 비용·epoch 수·정책 최대 길이: `TAKRAW_CLUB_RULES.learning`
- 조정 값 이름·범위: `TAKRAW_TUNING`
- 저장 필드: 클럽 레코드 `learning` (선택 필드, 없는 이전 저장본도 유효)

## 시험

`RAPIER_MODULE=<rapier.mjs 경로> npx playwright test learning-feature learning.spec` → 15개 통과.

- 클럽 저장 형식: 학습 필드 선택/엄격 검증, 포인트 차감·부족 거부·거부 시 불변
- 팀 조정기: 상대가 치기 전에는 호출 안 함, 치고 난 뒤 가장 가까운 아군 기준 1회 호출, 해제
- 학습 실행: 전후 비교 n, 저장 형식 왕복(출력 동일), 깨진 값 무시, 이어서 학습, 중단 시 정책 없음
- 90초 AI 경기(스크래치 스크립트): 튜너 연결 시 스파이크마다 호출됨, 튜너 없으면 호출 0·조정 없음

## 실행하지 못했거나 재지 않은 것

- E2E(브라우저)와 학습 화면의 실제 렌더링: 샌드박스에 CDN 접근과 화면 표시가 없어 실행하지 못했다. 클럽 대화창 안의 버튼 배치와 모바일 레이아웃은 눈으로 확인하지 않았다.
- 휴대폰에서의 학습 시간(데스크톱 샌드박스 기준 100회 약 30초)과 화면 끊김.
- 학습한 팀 대 규칙 AI 팀의 경기 승률. 지금 보는 지표는 스파이크 받기 장면 성공률뿐이다.
- 학습 중 샘플 장면 재생(고스트)은 이번 범위에 넣지 않았다. 보상 곡선과 전후 성공률만 보여 준다.
- 온라인: 적용하지 않는다. 양쪽 가중치 일치를 확인하는 절차가 먼저 필요하다.
