# 동료 AI 학습 기능 (v0.12.13)

> v0.12.16부터 학습 화면과 경기 적용은 제거했다(데이터·학습 계층은 유지). 이 문서는 v0.12.15까지의 동작과 측정 기록이다. 현재 상태와 이어서 할 일은 [learning-tobe.md](../learning-tobe.md).

2026-10-27. 학습 코어([learning-core.md](learning-core.md))를 유저 기능으로 연결했다.

## 동작

1. 홈 → 내 팀 관리 → "동료 AI 학습" 버튼으로 학습 화면을 연다.
2. 훈련 포인트 1 P로 학습을 시작한다. 같은 스파이크 16개로 학습 전 성공률을 재고, 스파이크 100번 받기(REINFORCE, 장면마다 화면에 양보)를 돌리고, 4비트로 양자화한 가중치로 학습 후 성공률을 잰다.
3. 끝까지 마친 경우에만 포인트 1을 차감하고 정책(base64 약 190자)과 누적 횟수를 클럽 레코드에 저장한다. 중간에 멈추거나 오류가 나면 포인트도 저장도 바뀌지 않는다.
4. 다음 로컬 AI 대전부터 우리 팀 동료는 상대 스파이크마다 정책이 낸 조정 값을 쓴다. 학습 이력이 있으면 저장된 가중치에서 이어서 학습한다.

## 규칙의 위치(SSOT)

- 비용·epoch 수·정책 최대 길이: `TAKRAW_CLUB_RULES.learning`
- 조정 값 이름·범위: `TAKRAW_TUNING`
- 저장 필드: 클럽 레코드 `learning` (선택 필드, 없는 이전 저장본도 유효)

## 시험

학습 테스트는 스위트에서 제외했다(자동 검증 없음).

- 클럽 저장 형식: 학습 필드 선택/엄격 검증, 포인트 차감·부족 거부·거부 시 불변
- 팀 조정기: 상대가 치기 전에는 호출 안 함, 치고 난 뒤 가장 가까운 아군 기준 1회 호출, 해제
- 학습 실행: 전후 비교 n, 저장 형식 왕복(출력 동일), 깨진 값 무시, 이어서 학습, 중단 시 정책 없음
- 90초 AI 경기(스크래치 스크립트): 튜너 연결 시 스파이크마다 호출됨, 튜너 없으면 호출 0·조정 없음

## 실행하지 못했거나 재지 않은 것

- E2E(브라우저)와 학습 화면의 실제 렌더링: 샌드박스에 CDN 접근과 화면 표시가 없어 실행하지 못했다. 클럽 대화창 안의 버튼 배치와 모바일 레이아웃은 눈으로 확인하지 않았다.
- 휴대폰에서의 학습 시간(데스크톱 샌드박스 기준 100회 약 30초)과 화면 끊김.
- 학습한 팀 대 규칙 AI 팀의 경기 승률. 지금 보는 지표는 스파이크 받기 장면 성공률뿐이다.
- 학습 중 샘플 장면 재생(고스트)은 이번 범위에 넣지 않았다. 보상 곡선과 전후 성공률만 보여 준다.
- 온라인: 적용하지 않는다. 양쪽 가중치 일치를 확인하는 절차가 먼저 필요하다.

## 경기 득점 비교 (v0.12.14, 2026-10-27)

스파이크 받기 장면 성공률이 실제 경기 득점으로 이어지는지 `scripts/learning-match-bench.mjs`로 쟀다. 같은 조건(시작 tick 오프셋 24가지)에서 학습한 조정을 쓰는 팀을 team 0과 team 1에 번갈아 두고, 규칙 AI끼리 붙인 상대 팀과 180초씩 득점을 센다. 조건당 2판, 정책마다 48판. 학습 정책은 시드 1의 REINFORCE 선형 정책(4비트 저장 가중치).

| 정책 | 학습 팀 득점 : 실점 | 득점률 | 판당 득실 평균 ± 표준오차 | 이김 / 짐 |
| --- | ---: | ---: | ---: | ---: |
| 대조군: 조정값이 기본값과 같은 정책 | 225 : 225 (24판) | 0.500 | 0 | 12 / 12 |
| 스탯 5, 학습 조정을 계속 적용(v0.12.13) | 210 : 756 | 0.217 | −11.4 ± 0.9 | 0 / 48 |
| 스탯 20, 학습 조정을 계속 적용(v0.12.13) | 198 : 804 | 0.198 | −12.6 ± 0.6 | 0 / 48 |
| 스탯 5, 받는 첫 접촉 뒤 해제(v0.12.14) | 378 : 474 | 0.444 | −2.0 ± 0.4 | 12 / 36 |
| 스탯 20, 받는 첫 접촉 뒤 해제(v0.12.14) | 402 : 468 | 0.462 | −1.4 ± 0.6 | 18 / 30 |

- 규칙 대 규칙에서 team 0의 득점률은 0.453이다(자리 편향). 학습 팀을 양쪽에 번갈아 두는 비교에서는 이 편향이 상쇄되며, 대조군이 정확히 0.500으로 나와 측정 장치에 치우침이 없음을 확인했다.
- v0.12.13은 받기 학습으로 정한 값(예: `aimDx` 0.70 → 0.31, `contactHeight` 0.75 → 0.89, `strokeTime` 0.12 → 0.166)을 다음 상대 스파이크까지 계속 썼다. 이 값은 세터 토스와 공격에도 적용되어 48판을 모두 졌다.
- v0.12.14는 받는 첫 접촉과 득점 직후에 조정을 기본값으로 되돌린다. 손실은 줄었지만 규칙 AI보다 득점률이 0.04~0.06 낮다(−1.4 ~ −2.0점/판, 표준오차 0.4~0.6의 약 2.4~5배).
- 결론: 현재 학습 목표(고립된 한 명의 스파이크 받기 성공률)는 실제 경기 득점을 올리지 못한다. 학습 화면의 "전후 성공률"은 오르지만, 그것이 경기 실력 향상이라는 증거는 아니다.
- 원인 후보(미검증): 학습 장면은 세터(id 1) 한 명, 낙하점 범위와 공 속도 범위가 고정된 한 종류다. 경기에서는 착지점에 가장 가까운 선수가 받고, 공 궤적이 다양하다. 성공 판정(우리 코트 안, 정점 2.0 m 이상, 동료가 닿음)도 이후 득점과 직접 이어지지 않는다.
- 재현: `TRAIN_ONLY=1 CACHE=정책.json STATS=5,20 node scripts/learning-match-bench.mjs` 로 학습을 저장한 뒤 `CACHE=정책.json EVAL=5 MATCHES=24 node scripts/learning-match-bench.mjs`.
