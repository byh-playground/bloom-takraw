# 경기 단위 파라미터 학습 (v0.12.22)

2026-10-27. 결론: **득점률이 오르지 않아 경기에 연결하지 않았다.** 코드·벤치·시험만 남긴다.

## 방법

- 입력: 상수 1, 우리 팀이 서브권인지(0/1). 정책: 선형, 시작 가중치 0(= 규칙 AI 기본값). 출력: 조정 값 8개(aimDx, aimDz, attackApex, lead, followThrough, braking, contactHeight, strokeTime).
- 랠리마다 `game.setTuning(team, 값)`으로 조정 값을 뽑아 적용하고, 랠리 끝에 득점 +1 / 실점 −1로 REINFORCE 갱신(탐색 σ 0.3, 학습률 0.02, 16랠리 배치, 이동평균 기준선).
- 학습: 시드별 60판(좌우 번갈아, 판마다 다른 경기 시드). 평가: 학습 끝난 정책의 평균 행동(탐색 없음)을 대조군(조정 0)과 48판(24조건 × 좌우 2판) 대결.
- 실행: `RAPIER_MODULE=… TRAIN=60 EVAL=24 SEED=<n> node scripts/match-learning-bench.mjs`

## 결과

| 시드 | 대조군 득점률 | 학습 정책 득점 : 실점 | 학습 정책 득점률 |
| --- | --- | --- | --- |
| 1 | 0.500 | 322 : 292 | 0.524 |
| 2 | 0.500 | 265 : 364 | 0.421 |
| 합 | 0.500 | 587 : 656 | 0.472 |

- 학습 중 최근 5판 득점률은 0.29~0.50 사이를 오가며 오르는 추세가 없었다. 가중치 크기는 0.25 → 0.57로 커졌다(움직이긴 했으나 득점과 이어지지 않음).
- 시드 간 편차(0.524 / 0.421)가 평균과 대조군의 차이보다 크다. 현재 설정으로는 학습 효과를 확인하지 못했다.
- 대조군이 0.500이므로 측정 장치는 정상이다.
