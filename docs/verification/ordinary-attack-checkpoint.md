# 일반 공격 선행 오류 조사 체크포인트 (v0.12.23)

학교 표시 1단계와 분리한 PR21이다. 기준 main은 `fbf04e04ff789b21ab3f1e755fc29b7d0238ac14`다. **아직 해결 및 머지 조건을 충족하지 못했다.** 초기 팔 자세 문서의 소수 seed 결과만으로 전체 성공을 주장하지 않는다.

## 현재 수정 범위

- 일반 지상 cushion 토스에서 기존 런지·슬라이드의 팔 접기 자세를 재사용한다. 모든 팔 충돌체는 유지한다.
- AI 수신 예약의 유효 기간을 물리 동작의 절대 `contactAt`으로 확인한다. 남은 시간이 0인 예약을 현재 시각으로 계속 갱신하던 경로를 제거하고 recover 상태를 다시 잠그지 않는다.
- 궤적 변경이나 만료된 수신 동작은 기존 조작 계약으로 입력을 한 틱 해제한 뒤 새 킥 edge로 재계획한다. 공 속도 직접 쓰기나 강제 접촉은 없다.
- 사용자 흐름 실패 증거에 실제 seed를 포함한다. 무작위 seed 선택과 80% 기준은 유지한다.

## 확인한 결과와 한계

최초 팔 자세 수정은 실제 Rapier 0.21.0 헤드리스 seed 1에서 3/5를 5/5로 개선했고 seed 2는 5/5였다. 그러나 이어진 원래 전체 `npm test`는 공격 성공률 40%로 실패했다.

원래 E2E에서 실패한 seed는 `1733474506`, `1767208846`이다. 후자의 첫 우리 서브 5회를 고정 순서로 추적했다. 수신 계획의 재잠금 문제는 별도 저장 상태 재현에서 확인했지만, 그 저장 상태는 실험 후보에서 생성됐으므로 새 경기 성공률 근거로 쓰지 않는다.

새 경기에는 서로 다른 실패 경로가 남아 있다.

1. 서브: target 없는 return 경로는 고정 발 방향·속도를 사용하며 토스의 발등 법선 정렬 경로와 다르다. 발 앞 모서리 접촉과 네트 아래 통과가 관측됐다.
2. 세터: 지정된 정상 패스는 `isReceiveBall`에서 수신 방어 계획을 생략한다. 세터가 떨어지는 공을 향해 이동하다 발보다 몸통·골반이 먼저 닿는 사례가 있다. 충돌 경로 회피 보완은 미완료다.
3. 공중 공격: 계획 타점보다 실제 접촉이 늦고 낮다. 실패 seed의 랠리 6·8에서 계획과 접촉 사이 약 27~56ms, 높이 약 9~32cm 차이가 관측됐다. 이는 실험 후보 관측치이며 현재 수정의 개선 근거가 아니다.

발 목표 좌표 통합, 준비 시간 연장, 기본 공중 킥 속도로 각도 계산, 강성·관성 기반 감쇠 후보는 재현 성공률을 충분히 개선하지 못해 되돌렸다. 재현 코드와 원시 로그·패치는 Git 제외 `artifacts/`에 보존했다. 테스트 완화나 유리한 seed 고정은 하지 않았다.

## 검증 자료

- `artifacts/seed1767208846-contact-feedback.json`: 현재 최소 후보의 첫 우리 서브 5회 결과.
- `artifacts/air-contact-target-trace.json`: 실패 후보의 공중 계획·실제 충돌 법선·타점 기록.
- `artifacts/rejected-nominal-air-target.patch`, `artifacts/rejected-nominal-air-target-result.json`: 기본 속도 후보와 실패 결과.
- `artifacts/rejected-critical-ground-and-air-damping.patch`, `artifacts/rejected-critical-ground-and-air-damping-result.json`: 감쇠 후보와 실패 결과.
- `artifacts/expanded-contact-with-timing-candidate.patch`: 되돌린 좌표·준비 시간 확대 후보.
- `artifacts/latest-required-test.log`: 최소 후보의 전체 검사 실패 로그. 27개 통과·10개 생략·1개 실패, `user-flow.spec.js:104` 공격률 0.6/기준 0.8, 113706ms, timeout 없음.

전체 검사 뒤 sync 검사가 같은 `artifacts/e2e/`를 초기화해 해당 전체 실행의 JSON 보고서는 보존하지 못했다. 위 텍스트 로그와 직접 읽은 종료 상태는 남아 있다. 최신 무작위 실행의 seed는 복구하지 못했으므로 앞서 보존한 두 seed와 혼동하지 않는다.

현재 최소 후보의 seed `1767208846` 결과는 1/5다. 랠리 2는 서브 네트 아래 통과, 4는 성공, 6은 낮은 마지막 지상 타격 후 바닥, 8은 세터 몸통 접촉 후 아웃, 10은 세터 발 접촉 후 바닥이었다. `npm run check`와 `npm run verify:dependencies`의 9개 해시는 통과했다. CDN 검증은 샌드박스 DNS 실패 후 허용된 네트워크 환경에서 재실행했다.

필수 3검사 모두 통과하기 전 PR21은 초안으로 유지한다. PR20 학교 외형과 10개 캡처도 보존하며, PR21 통과·머지 후 최신 main에서 PR20을 재검증한다. 2~10단계는 아직 시작하지 않았다.
