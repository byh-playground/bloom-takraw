# 3단계 임시 단판 규칙 (v0.12.25)

출시 전 임시값은 7점·듀스 시작 6점·상한 9점·1세트다. 기존 듀스 방식을 유지하므로 6:6에 도달하면 먼저 9점을 얻는 팀이 이긴다. 7:6이나 8:6에서는 끝나지 않는다. 도움말도 같은 규칙을 설명하고 `sets === 1`이면 두 세트 마크와 세트 번호를 숨긴다.

기존 사용자 흐름의 첫 일반 서브 표본은 총 10회, 성공률 기준은 80%를 유지한다. 짧은 단판이 표본 5회 전에 끝나면 실제 다시 경기 버튼으로 이어서 관찰한다. 승패·seed·실패를 골라 버리지 않고 각 표본의 seed를 기록한다. 기존 공격률 실패 한 건의 승인 예외는 유지하고 다른 실패에는 적용하지 않는다.

`artifacts/measure-short-matches.mjs`는 실제 pinned Rapier로 6:0·6:6·8:6·8:8 경계를 확인하고, 기본 클럽 3명 대 기본 상대의 모든 선수 AI 경기 24개(seed 1~24)를 끝까지 실행한다. `school-03-duration.json`과 로그에 각 경기 simulation 초와 실제 실행 초를 별도로 기록한다. 평균 약 2분은 임시 목표이며 실측에 맞춰 보고한다. 측정은 렌더링이 없는 순차 CPU 실행이다.

온라인은 양쪽 같은 v0.12.25가 필요하다. 런타임은 GameKit 세션의 `simulationVersion`에 버전을 전달하고 저장 snapshot 검증도 config.version 일치를 요구한다. 동기화·불일치 실제 확인과 지정 3검사 결과, 측정 평균은 PR 본문에 기록한다. 확인하지 못한 네트워크 항목은 미검증으로 명시한다.
