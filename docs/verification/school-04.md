# 4단계 도장깨기 (v0.12.26)

홈의 도장깨기 버튼은 기존 modal-layer/dialog-panel에 학교 목록을 연다. 각 카드는 학교명·유니폼 견본·잠김/클리어·도전/재도전을 표시한다. 첫 학교부터 순서대로 승리하면 다음 학교가 열리고 이미 클리어한 학교도 재도전할 수 있다. 1단계의 임시 상대 선택은 제거했다. 일반 AI 경기·훈련·온라인의 시작 경로는 유지한다.

클럽 저장의 선택 필드는 `campaign: { cleared: string[] }`다. 없는 구 저장은 허용하고 있으면 객체·배열·알려진 ID·중복·학교 순서를 엄격히 검사한다. 진행 상태는 이 배열 하나에서 읽는다. 승리 관측은 기존 경기 보상 큐에 학교 ID를 함께 담고, IndexedDB의 기존 보상 트랜잭션 안에서 클리어와 경기 보상을 함께 기록한다. 같은 경기 ID의 재시도는 중복 처리하지 않는다. 최초 클리어 추가 포인트는 6단계 범위이며 이번 단계에 넣지 않는다.

`tests/campaign.spec.js`는 구 저장 호환·잘못된 형식 거부·순서 해금·패배·재도전·동일 보상 재시도를 확인한다. 기존 학습 기능은 활성화하지 않았다.

브라우저 자료는 `artifacts/school-04/`에 있다. 390×844에서 클리어 전후 목록을 캡처했다. 390×540에서는 콘텐츠 697px/보이는 영역 345px, scrollTop 352px까지 이동했다. 새로고침 후 첫 클리어와 다음 해금, 재도전 후 중복 없는 배열을 확인했다. 저장 흐름 확인의 승리는 `awardPoint` 경계 fixture이며 실제 물리 경기 승리로 주장하지 않는다. 구 저장 fixture는 해당 선택 필드를 제거한 실제 IndexedDB 레코드를 새로 읽었다.

실제 모바일 기기·GPU는 미검증이고 Chromium 소프트웨어 렌더링으로 확인했다. 지정 3검사 결과는 PR 본문에 기록한다. 기존 공격 성공률 80% 실패 한 건만 승인 예외이며 그 뒤 Nostr/WebRTC 구간은 미검증 후속 목록에 유지한다.
