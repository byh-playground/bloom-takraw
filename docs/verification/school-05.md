# 5단계 학교 AI 성향·능력 (v0.12.27)

학교의 `ai`는 Temperament 설정과 역할별 선수 능력 프리셋을 가진다. runtime은 로컬 AI 경기에서 이 데이터를 일반 팀 프로필과 성향 데이터로 변환해 전달한다. simulation은 학교를 import하거나 학교 ID로 분기하지 않는다. 온라인·훈련·로컬 2인은 기존 기본 Temperament를 사용한다. 기존 학습 기능은 활성화하지 않았다.

반응 시간·동료와의 간격·기본 위치 깊이·좌우 흔들림은 기존 Temperament 생성 경로로 전달한다. seededUnit 함수와 seed·선수·랠리 해시 규칙은 변경하지 않았다. 팀 성향은 snapshot의 `temperamentProfiles`에 저장·엄격 검증·복구해 재실행 시 동일한 설정을 사용한다. 입력 형식과 물리 타격 계약은 유지한다.

능력값을 일괄 높인 초기 뒤 두 조합은 더 강해지지 않았다. 이동·점프·유연성을 기본값으로 유지한 조합도 측정하고, 실제 측정된 다섯 조합을 난이도 순서로 배치했다. 현재 예비 조합 순서는 아래와 같다. **각 10경기 예비값이며 학교당 100경기 결과가 아니다.**

| 배치 학교 | 우리 득점 점유율(예비) | 원자료 |
| --- | ---: | --- |
| 새싹고 | 0.6355 | pilot의 sprout |
| 불꽃고 | 0.5826 | pilot-back의 moon |
| 파도고 | 0.5086 | pilot의 flame |
| 번개고 | 0.4545 | pilot의 wave |
| 달빛고 | 0.4370 | pilot-back의 bolt |

프로필과 수치는 임시다. 목표는 첫 학교 약 0.65에서 마지막 약 0.40으로 감소하는 방향이다. 우리 전 능력 기본 50·모든 선수 AI·동일 seed 1~100·실제 7점 단판으로 5개 프로필을 각각 100경기, 총 500경기 끝까지 실행했다. 득점 점유율은 우리 총점/(우리 총점+상대 총점)이고 승률과 구분한다. 표본이나 실패 경기를 선별하지 않았다.

측정 코드는 Git 제외 `artifacts/measure-school-ai.mjs`, `school-ai-worker.mjs`다. 렌더링 없이 CPU 작업자 4개로 분할하며 원시 경기 결과·프로필·소스 hash·수비 위치/반응 샘플을 보존한다. 예비 50경기는 실제 약 234초였다. `school-05-pilot.json`, `school-05-pilot-back.json`은 예비 원자료이고 `school-05-final.json`이 본 측정 원자료다.

## 100경기 결과와 최종 배치

본 측정의 번개 조합이 달빛 조합보다 강해 두 AI 조합의 학교 배치를 교정했다. 원시 결과의 측정 라벨·점수·seed는 고치지 않았다. 아래는 **각 100경기가 실행된 동일한 수치 프로필**을 최종 학교에 대응한 표다. `school-05-assignment.json`은 SHA-256 프로필 일치, seed 1~100 중복/누락 없음, 실제 7점/9점 종료와 총점 집계, 배치의 단조 감소를 검사한다. AI는 학교 이름으로 분기하지 않고 정수 선수 ID로 해시하므로 학교 표시 라벨 변경은 수치 모델에 사용되지 않는다.

| 최종 학교 | 원자료 슬롯 | 경기 수 | 우리:상대 총점 | 우리 득점 점유율 |
| --- | --- | ---: | ---: | ---: |
| 새싹고 | sprout | 100 | 689:393 | 0.6368 |
| 불꽃고 | flame | 100 | 622:482 | 0.5634 |
| 파도고 | wave | 100 | 610:526 | 0.5370 |
| 번개고 | moon | 100 | 600:578 | 0.5093 |
| 달빛고 | bolt | 100 | 562:631 | 0.4711 |

이 표본에서는 단조 감소한다. 첫 목표 0.65 대비 -1.32%p, 마지막 목표 0.40 대비 +7.11%p다. **마지막 학교의 0.40 목표는 미달**이며 추가 균형 교정 후속 항목으로 남긴다. 목표를 맞췄다고 주장하지 않는다. 원자료 SHA-256은 `c6ad1b1412039ab0ed315dd8890d50edf12102fe8a0d6075e7fc6f5daadd5c4e`다.

새 성향 범위·동일 seed 해시·snapshot 복구 검사 2개, 실제 Rapier 동기화 5개, 5학교 런타임 성향/능력 전달과 훈련/로컬 기본값 복귀를 통과했다. 최종 배치의 지정 3검사 결과는 PR에 기록한다. 기존 공격률 80% 실패 한 건의 사용자 승인 예외를 유지하며 다른 실패는 수정한다.
