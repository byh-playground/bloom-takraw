# 6단계 첫 클리어 훈련 포인트 (v0.12.28)

학교별 임시 보상은 새싹 3·불꽃 4·파도 5·번개 6·달빛 8 P이며 `schools.js`의 `firstClearTrainingPoints`가 단일 출처다. 도장깨기의 훈련 포인트는 첫 클리어에만 지급하고 재클리어와 패배에는 지급하지 않는다. 일반 AI 경기의 기존 훈련 포인트와 크레딧 규칙은 유지한다.

첫 클리어 판정과 다음 학교 해금은 기존 `campaign.cleared`만 사용한다. 별도 보상 수령 플래그는 없다. 클리어 배열 갱신과 포인트 지급은 같은 IndexedDB 트랜잭션에서 처리하고 동일 경기 ID의 재시도는 기존 보상 ID 경로로 중복 방지한다. 이미 클리어된 구 저장에는 다시 지급하지 않는다.

`lastReward.schoolId`는 마지막 영수증 표시용 선택 메타데이터이며 지급 판정에 쓰지 않는다. 과거 영수증의 비음수 정수 금액은 임시 보상값이 바뀌어도 읽을 수 있다. 일반 AI 영수증의 기존 검증은 유지한다. 결과 화면은 저장 후 실제 지급액을 읽어 표시한다.

`tests/campaign.spec.js`의 3개 검사가 구 저장·형식·해금·패배·재시도·저장 복구·재클리어·일반 AI 보상을 확인한다. `artifacts/school-06/evidence.json`의 실제 IndexedDB 브라우저 흐름은 첫 보상 전 6 P, 승리 후 9 P, 새로고침 후 재도전 승리 뒤에도 9 P였다. 승리는 저장 검증용 `awardPoint` fixture이며 물리 경기 승리로 주장하지 않는다. 390×844 캡처 2개와 좁은 화면 스크롤도 같은 폴더에 보존했다.

지정 3검사 결과는 PR에 기록한다. 기존 공격률 실패 한 건만 승인 예외다. 실제 모바일 기기·GPU와 해당 assertion 뒤 Nostr/WebRTC 구간은 미검증이다.

5단계의 실제 점유율 0.6368→0.5634→0.5370→0.5093→0.4711은 사용자가 수용했다. 최초 목표와 차이는 해당 보고서에 남기며 추가 0.40 교정은 필수 후속 항목에서 해제했다.
