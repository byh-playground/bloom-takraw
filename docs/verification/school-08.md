# 8단계 스파이크 득점 표시 감속 (v0.12.30)

확정된 기존 point 이벤트 직전 원인이 ground이고 마지막 실제 접촉이 득점 팀의 spike일 때만 로컬 AI 경기에서 표시 포즈를 500ms 동안 0.5배 속도로 읽는다. 서브 시 이전 접촉 기록을 비워 이전 랠리의 스파이크를 재사용하지 않는다. 온라인·훈련·로컬 2인과 효과 축소에서는 비활성이다.

GameKit frame에는 실제 단조 증가 시각을 그대로 전달한다. 독립 표시 버퍼는 포즈 수치만 복사하며 원본 frame, 입력과 simulation에는 쓰지 않는다. 감속 후 1.5배 속도로 표시 지연을 회수한다. 세션 생성 시 초기화한다. 이 시간·속도는 임시 연출 값이다.

`artifacts/verify-score-motion.mjs`와 `school-08-motion.json`: 선형 포즈 250ms→125, 500ms→250, 1000ms→1000 확인. 비활성 시 원본 포즈를 즉시 읽는다. 실제 Rapier 게임 두 개에 동일 입력으로 240 step을 실행해 매 step save SHA256이 동일했고 원본 포즈 불변, 양쪽 tick 240을 확인했다. 스파이크 바닥 득점·일반 접촉·상대 스파이크 아웃·네트 원인 4분기를 확인했다. 이것은 렌더 경로 fixture이며 실제 스파이크 득점 영상을 재현한 검사는 아니다.

check·verify:dependencies 통과, 실제 Rapier sync 5/5 통과. npm test는 31개 통과·11개 생략·기존 공격률 0.70 < 0.80 한 건 실패했다. 원본 artifacts/e2e는 school-08-final-test에 보존했다. 실제 기기·실제 WebRTC·실제 스파이크 득점 체감은 미검증으로 머지 후 확인 대상이다. 기존 공격 성공률 한 건은 승인된 머지 예외로 유지한다.
