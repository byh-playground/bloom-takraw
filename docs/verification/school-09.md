# 9단계 모바일 표시 (v0.12.31)

600px 이하에서 모든 버튼의 조작 영역을 44px 이상으로 유지한다. 종료 카드는 문구와 버튼을 행으로 정리하고 도장깨기 카드를 좁은 화면에 맞췄다. 매치포인트 배너를 카메라의 기존 상단 여백 안으로 옮기고 표시 중에는 일반 랠리 안내를 숨겨 서로 겹치지 않게 한다. 시뮬레이션·입력 인코딩·카메라 설정은 바꾸지 않았다.

`artifacts/verify-school-mobile.mjs`: Windows Chromium 390×844 mobile/hasTouch 에뮬레이션. 실제 휴대기기는 미검증이다. 상단 버튼 44×44, 점프 72×72, 발차기 88×88 확인. 학교 목록은 844px 높이에서 전체 표시되며 540px 높이에서 scrollHeight 647 / clientHeight 441 / scrollTop 206으로 마지막 학교까지 접근했다.

기존 카메라에 표시 포즈만 바꾸는 18개 공 위치 fixture(x -5/0/5, 높이 1/5/9, z ±2)에서 점수판 영역 y64–112와 공 투영의 겹침은 0개였다. 실제 경기 전체 궤적을 보장하는 검사는 아니다. 전후 game.save와 입력 바이트가 동일했다. 증거와 캡처는 `artifacts/school-09/`, 전체 검사 원본은 PR 경로에 기록한다. 실제 기기와 장시간 실제 경기의 가림 확인은 머지 후 확인 대상이다.

check·verify:dependencies 통과. npm test는 실제 터치 조작 시나리오 포함 31개 통과·11개 생략·기존 공격률 0.40 < 0.80 한 건 실패했다. 해당 실패만 승인된 예외이며 기준과 난수는 유지했다. `artifacts/school-09-test.log`, `artifacts/school-09-final-test/`에 원본을 보존한다.
