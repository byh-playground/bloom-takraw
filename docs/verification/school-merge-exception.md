# 학교 표시 1단계 머지 예외

사용자가 기존 `tests/user-flow.spec.js:104`의 공격 성공률 80% 실패 한 건만 머지 예외로 승인했다. 검사와 기준, 무작위 seed 선택은 그대로 유지한다. 다른 검사 실패나 새 회귀에는 이 예외를 적용하지 않는다.

학교 외형 PR20은 PR21 공격 수정과 분리했다. 기준 main `fbf04e0`은 그대로이며 학교의 표시 데이터와 렌더링만 변경했다. 학교 교체 전후 `save()` 동일성은 데스크톱·390×844, 5개 학교의 10개 경우 모두 참이고 실제 Rapier 동기화 검사 5개가 통과했다. 화면 자료는 `artifacts/school-01/`의 10개 PNG와 `evidence.json`에 보존했다.

`npm run check`, `npm run verify:dependencies`를 다시 통과했다. 전체 검사 실행 결과와 승인된 예외 적용 여부는 PR20 본문에 기록한다. Nostr/WebRTC 및 이후 흐름은 앞선 공격률 assertion에서 중단되어 미검증이며 후속 확인 목록에 남긴다. 실제 모바일 기기·GPU는 미검증이고 캡처는 Chromium 소프트웨어 렌더링이다.

PR21은 초안으로 보존하며 학교 단계에 포함하지 않는다. 기존 Pages의 main 배포 경로를 유지하고 Stable 승격은 하지 않는다.
