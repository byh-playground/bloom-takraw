# 접촉 타이밍 효과

2026-10-26, v0.12.11 Candidate. 사람 선수의 공중 발 접촉에 타이밍 등급(퍼펙트·굿·보통)을 붙이고 등급별 시각·음향 효과를 더했다. 경기 결과(공의 속도·궤적·득점)는 바꾸지 않는 표시 전용 변경이다.

## 변경 범위

- `simulation/timing.js`: 오차 공식과 등급 판정. 기록은 `state.timing`(팀별 최근 점프·발차기 입력)에 저장되어 스냅샷에 포함된다.
- 접촉 이벤트에 `timing: { grade, error, jump, kick }` 추가. 오차 단위는 초이며 음수는 빠름, 양수는 늦음이다. 점프와 발차기 중 오차가 큰 쪽이 등급을 정한다. AI 선수와 지상 접촉에는 `timing`이 없다.
- `presentation/impact.js`: 등급별 링·입자·바깥 링·표시 전용 정지(0.07초)·카메라 진동·공 궤적 강조. `presentation-events`의 `update(handle, ageMs)`와 `reconcile`, `object-pool`, `deterministic`의 시드 난수를 사용한다.
- HUD 등급 표시, `kickGood`·`kickPerfect` 소리.
- 연습의 `jumpOffset`·`kickOffset` 계산식을 같은 판정 클래스로 옮겼다. 연습 결과 문구와 판정은 바꾸지 않았다.

## 등급 창 실측

헤드리스 Rapier(0.21.0)에서 연습 모드의 봇이 점프 시점(e)과 발차기 시점(d)을 바꿔 50회 시도했다. 봇은 같은 입력 틱 규칙으로 점프·발차기 입력을 보내며, 시뮬레이션 코드는 실제 게임 모듈을 그대로 사용했다. 실제 사람의 입력이 아니다.

| 항목 | 값 |
| --- | --- |
| 시도 | 50회 |
| 발이 공에 닿은 시도 | 12회 |
| 닿은 시도의 최대 오차 크기 | 0.058초 |
| 닿은 시도의 발차기 오차 범위 | -0.038 ~ +0.028초 |
| 닿은 시도의 점프 오차 범위 | +0.008 ~ +0.058초 |

현재 임계값(perfect 0.02초, good 0.04초)으로 12회를 나누면 퍼펙트 4회, 굿 2회, 보통 6회다. 처음 가설(0.04초·0.08초)에서는 닿은 시도 대부분이 퍼펙트·굿이어서 등급이 의미 없었기 때문에 실측으로 낮췄다.

| 점프 오차 | 발차기 오차 | 오차 크기 | 등급 |
| ---: | ---: | ---: | --- |
| +0.058 | -0.022 / -0.005 / +0.012 | 0.058 | 보통 |
| +0.041 | -0.038 / -0.005 / +0.012 | 0.041 | 보통 |
| +0.024 | +0.012 | 0.024 | 굿 |
| +0.024 | +0.028 | 0.028 | 굿 |
| +0.008 | +0.012 | 0.012 | 퍼펙트 (4회) |

한계: 봇은 안내 시점보다 일찍 점프하지 못해 점프 오차의 음수 쪽은 측정하지 못했다. 입력 틱이 1/60초 간격이라 값이 틱 단위로 뭉친다. 임계값은 사람 플레이로 다시 보정해야 한다.

## 자동 검증

- `npm run check` 통과.
- 시뮬레이션 헤드리스: 같은 입력 두 번 실행에서 상태·이벤트 동일, 점프 중 `save()`→`load()` 후 재개한 실행이 중단 없는 실행과 동일, `state.timing`이 스냅샷에 포함됨.
- `TakrawImpactEffects` 12개 시나리오 통과: 정지 구간의 첫 모습 유지, 타이밍 없는 접촉이 이전과 같은 수명·입자 수, 같은 `tick`·`sequence`의 같은 입자 방향, 프레임 분할과 무관한 모양, 재확정 시 경과 시간 유지, 진동·궤적 강조의 지속 시간, 동작 줄이기, 풀 재사용과 중복 반납 무시, `PresentationEventQueue`와 같은 어댑터 모양으로 예측 시작·재확정·롤백 취소·만료.

## 미실행 범위

- `npm test`(Playwright 사용자 흐름)와 `npm run verify:dependencies`는 이 환경에서 브라우저·CDN에 접근할 수 없어 실행하지 않았다. 새로 고정한 `object-pool` 모듈의 SHA-256은 고정 배포 커밋의 파일 바이트와 직접 대조했다.
- 실제 화면 모습(링·진동·궤적·HUD 배치)과 소리는 눈과 귀로 확인하지 못했다. 모바일 짧은 화면에서 등급 표시가 다른 UI와 겹치는지도 확인하지 않았다.
- 온라인 두 브라우저의 효과 일치는 실행하지 않았다.
- 공개 배포·Stable 승격은 이 기록만으로 뜻하지 않는다.
