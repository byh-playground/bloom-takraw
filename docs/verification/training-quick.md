# 연습: 속공(낮고 빠른 토스) 추가 (v0.12.37)

## 배경
속공은 이 게임에서 낮은 세트에 짧게 점프해 바로 차는 공격(`predictAerial`의 `shortJump`, `ai.toss.lowAttack`)이다. 연습 모드는 높은 토스만 줘서 이 안내(점프 버튼 짧게 누르고 떼기, 접촉 0.64초 전 점프)를 연습할 수 없었다.

## 변경
- 연습 화면에 "토스 종류" 선택(높은 토스 / 속공)을 추가했다. 동작 연습 선택과 독립이며, 서로 바꿔도 유지된다. 명령 번호 21·22(동작 5~9, 재시작 4와 겹치지 않음).
- 속공 토스(`feedQuick`, 설정 `training.quick`): 세터 옆에서 꼭짓점 3.5 m의 낮은 포물선으로, 공격수 앞 낙하 타점(낮은 공격 접촉 높이 중앙 2.825 m)에 닿게 공을 올린다. 토스 시각을 바로 기록해 발자국·점프 안내가 열린다.
- 세터 발 충돌에 맡기지 않은 이유: 세트 꼭짓점 목표를 3.0 → 3.4로 올리면 실제 꼭짓점이 2.05 → 4.45 m로 불연속하게 바뀌어(발 접촉 비선형) 낮은 공격 구간에 안정적으로 들어오는 목표값이 없었다.
- 성공 문구에 "속공 ·"이 붙는다. 도움말에 토스 종류 설명을 추가했다.

|---|---|---|

| 속공 | 6/6 | 6/6 |

## 미검증
- 사람이 직접 하는 조작감과 모바일 연습 화면의 선택 칸 배치(`mobile-flow`/`user-flow`는 이 환경에서 실행 불가).
- 경기 중 속공(세터가 낮게 올리는 상황)의 성공률은 이번에 바꾸지 않았다.
