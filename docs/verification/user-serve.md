# 사람 서브 (v0.12.43)

- 내 팀이 서브할 차례면 공격수(사람)가 뒤쪽 서브 자리(`ai.serve.spot`)에 서고, 공은 서버 앞 손 자리(`ai.serve.toss.offset` 0.65 m, 높이 1.0 m)에 멈춰 있다.
- **공 던지기 버튼**(키보드 E · 모바일 `공 던지기`, 서브 때만 보임): 누르는 동안 힘을 모으고 떼면 공이 위·앞으로 던져진다. 12초 안에 안 던지면 자동으로 던진다.
  - 짧게: 꼭짓점 1.6 m, 앞쪽 속도 0.3 m/s → 서버 바로 앞에 떨어져 **그 자리에서 지상 발차기**.
  - 0.8초 이상: 꼭짓점 4.4 m, 앞쪽 속도 1.5 m/s → 약 2.5 m 앞까지 날아가 **앞으로 달려가 점프 발차기**. 중간은 선형.
- 던진 뒤는 기존 조작(이동·점프·발차기)과 물리 그대로다. 지상 서브 발차기는 접촉 직후 상대 코트 뒤쪽 중앙(x 4.2 m)을 향한 포물선으로 보정한다(`assistServe`, 꼭짓점 3.8 m). 공중 발차기는 보정 없이 발 물리로 결정되어, 세게 맞으면 아웃이 날 수 있다.
- 서브 뒤에는 사람이 자기 자리로 돌아간다. 같은 팀 AI는 서브 공을 가로채지 않는다.
- 검증(`scripts/scene-serve.mjs`, 봇): 짧게 던져 지상 발차기 3/4 득점·1 핸드 반칙, 길게 던져 달려가 점프 발차기는 넘어가지만 아웃이 잦다(타이밍 조절 필요). `tests/user-serve.spec.js` 3개.
- 남은 일: 서브 종류·구역 다양화, 조준 입력.
